Tentang Sistem

Sistem ini dirancang untuk mendukung penelitian mengenai implementasi leaderboard Roblox berbasis REST API. Website berfungsi sebagai media monitoring data leaderboard yang sebelumnya hanya dapat dilihat di dalam game. Dengan adanya website ini, informasi pemain dapat diakses secara lebih fleksibel, terpusat, dan mudah dianalisis.

  • Menampilkan leaderboard pemain berdasarkan waktu tercepat.
  • Menyediakan profil pemain beserta statistik permainan.
  • Menyajikan informasi checkpoint map HYUHYU.
  • Dirancang agar dapat dihubungkan ke backend Node.js + Express dan database MongoDB Atlas.
